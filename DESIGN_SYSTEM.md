# Визуальный язык Plus360

Направление: спокойный Bauhaus для webatelier. Тёплая бумажная основа, графитовый текст, кирпичный акцент; приглушённые синий и охра для небольших деталей. Иерархия строится на типографике, отступах и границах поверхностей. Hero остаётся без изображений.

## Источник токенов

Тема: `assets/scss/var/_tokens.scss` — семантические цвета, поверхности, состояния, шкала отступов, размеры и движение. `assets/scss/var/_typo.scss` — типографика. `_base.scss` содержит только Sass breakpoints: CSS custom properties не применимы в условиях media queries.

Тёмная тема переопределяет семантические цвета через `data-theme="dark"`; компоненты используют те же токены. Выбор темы — существующее предпочтение в localStorage или системная настройка.

## Правила компонентов

- Цвета только из семантических токенов. HEX, RGB и новые палитры внутри компонентов не вводить.
- Размеры текста, насыщенность, интерлиньяж и межбуквенные интервалы брать из типографических токенов.
- Шкала отступов: `--space-1`…`--space-9`; адаптивные отступы — `--page-gutter`, `--section-gap`, `--hero-gap`.
- Геометрия: прямые углы у кнопок и карточек, небольшое скругление больших панелей и диалогов. Дуга под шапкой и круг перед названием atelier создают узнаваемость.
- При скруглении углов использовать `corner-shape: var(--corner-shape)`; общий токен — `squircle`. Правило задано для элементов и псевдоэлементов в базовом слое. Настоящие геометрические круги и дуга шапки используют `round`. При нулевом радиусе углы остаются прямыми; браузеры без поддержки corner-shape сохраняют обычный border-radius.
- Primary CTA: кирпичная заливка и контрастный текст. Вторичное действие: обычная текстовая ссылка. У каждой интерактивной сущности нужны hover, focus-visible и, где применимо, active/disabled.
- Быстрые ссылки hero: мягкая поверхность без тени, иконка и короткое название. Только на широких экранах.
- Карточки услуг: светлая поверхность, тонкая граница, спокойная типографика, выравнивание по левому краю. Без подъёма/масштабирования на hover.
- Преимущества: открытые текстовые колонки с верхней линией в кирпичном, синем и охристом цветах, чтобы отличаться от карточек услуг.
- Иконки линейные, одного размера и акцентного цвета; декоративные SVG имеют `aria-hidden`.
- Движение: `--transition-fast`, только обратная связь на действия. Учитывать существующий prefers-reduced-motion.
- Новые значения добавлять в источник токенов после проверки, что существующего токена недостаточно. Структурные CSS значения (`0`, `auto`, `1fr`, количество колонок, проценты) допускаются в компонентах.

## Статус внедрения

Новые правила применены к главной, шапке и подвалу. Предыдущие имена цветовых переменных сохранены как ссылки на новые семантические токены для совместимости остальных разделов.

Остальные компоненты ещё требуют последовательного переноса: каталог и подробные услуги, тарифы, FAQ, форма, диалоги, служебные страницы. Цвета тарифов, формы и диалогов также переведены на общие токены. Остальные типографические и геометрические значения старых компонентов ещё требуют унификации. Это следующий этап консистентности, а не завершённая миграция всего сайта.

Палитра и оформление оценены на локальной главной. Полный аудит контраста, состояний и адаптивности всех компонентов пока не проводился.

## Шрифт заголовков и акцентов

Jost, variable normal 100–900, источник: @fontsource-variable/jost 5.3.0. Заголовки используют насыщенность 500; акценты — 500–600. Основной текст остаётся нейтральным системным гротеском. Токены: `--font-display`, `--font-accent`, `--weight-display`.

WOFF2 размещены локально в теме: `static/fonts/jost/`. Подключены latin, latin-ext и cyrillic с unicode-range и font-display: swap; сторонних запросов для загрузки шрифта нет. Исходные файлы не изменялись.

Лицензия SIL Open Font License 1.1 и исходное уведомление copyright сохранены в `static/fonts/jost/LICENSE.txt`, публикуются по `/fonts/jost/LICENSE.txt`. Лицензия требует сохранения уведомлений при распространении, но не требует отдельного размещения в Impressum.

## Читаемость навигации (проверка 2026-10-01)

Меню и действия hero: `--text-nav`/`--text-action` = 1.0625rem (17 px при стандартном размере). Переключатель языка: `--text-language` = 1rem. Области нажатия навигации и действий hero имеют минимум 2.75rem по высоте; основные пункты меню также по ширине. Переключатель языков переносится на отдельную строку на мобильном экране. Кнопке меню добавлено локализованное доступное имя.

Контраст светлой темы: вторичный текст на поверхности шапки 4.94:1, текст быстрых ссылок hero 12.22:1, акцентная ссылка на фоне страницы 6.28:1, текст primary CTA 7.02:1. Проверено через Chrome DevTools: ширина 320 CSS px и увеличение корневого размера текста до 200%; это проверка увеличения текста, не полная проверка всех вариантов браузерного zoom. Исправлены выходящие за экран элементы. Полный аудит WCAG всего сайта остаётся отдельной задачей.

## Цветовое пространство

Все цвета палитры светлой и тёмной темы, включая overlay и тени, заданы в OKLCH. Значения переведены из исходного sRGB с сохранением текущих цветов; HEX в таблице выше оставлен как справочный эквивалент.

L — воспринимаемая светлота, C — насыщенность, H — оттенок. Тёмная тема имеет отдельные значения семантических токенов: фон, поверхности, текст и действия проектируются по своим ролям, без автоматической инверсии. Контраст проверяется отдельно; равномерность OKLCH не гарантирует соответствие WCAG.

Полупрозрачные статусные поверхности используют `color-mix(in oklab, ...)` для смешивания с поверхностями без обхода оттенков по цветовому кругу. Компоненты по-прежнему обращаются только к токенам и не вычисляют собственные цвета. Кнопка с иконкой в нижней строке подвала открывает native popover с radio-вариантами системной, светлой и тёмной темы. Позиционирование — CSS Anchor Positioning относительно кнопки, с переворотом у границ экрана и фиксированным fallback для браузеров без поддержки. Явный выбор сохраняется в localStorage (`theme`); системный режим удаляет сохранённое переопределение и следует изменениям prefers-color-scheme. Тема применяется в head до отрисовки страницы. Настройка синхронизируется между вкладками; при недоступном localStorage переключение работает в текущей вкладке.
