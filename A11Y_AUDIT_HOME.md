# Аудит доступности главной Plus360

Дата: 2026-10-01. Ревизии: основной проект `1f445ed`, тема `581891e`.

## Вывод

Основная структура и контраст главной хорошие. Первичный аудит выявил три дефекта A1–A3; они исправлены после аудита и повторно проверены в Chrome. Полное соответствие WCAG AA по-прежнему не заявляется: остаются проверки скринридерами, других браузеров и настоящего zoom.

Ниже сохранены исходные наблюдения для воспроизведения регрессий; текущий статус исправлений приведён в конце документа.

## Метод и границы

- Локальная версия `http://localhost:1313/` и `/ru/`, Chrome 154 через Chrome DevTools MCP.
- Ориентир: [WCAG 2.2, уровень AA](https://www.w3.org/TR/WCAG22/).
- DOM, accessibility tree, исходные шаблоны, стили и JavaScript; реальные нажатия Tab, Enter, ArrowUp, Escape.
- Ширины 1280 и 320 CSS px; высоты 900, 800 и 480 px.
- Светлая и тёмная темы; проверки текста 200% посредством корневого font-size. Это не браузерный zoom: проверка 320 px моделирует ширину reflow, но не весь сценарий zoom 400%.
- Проверка text spacing: line-height 1.5, letter-spacing .12em, word-spacing .16em, отступ после абзацев 2em, отдельно и совместно с увеличением текста.
- Lighthouse snapshot с axe-core 4.12.1: пять сохранённых результатов в `audits/home/lighthouse-summary.json`. В закрытом состоянии элементов управления все получили Accessibility 100. Эти проверки не выявили ручные проблемы ниже.
- Контраст рассчитан из фактических OKLCH-токенов после преобразования браузером в sRGB, по формуле относительной яркости WCAG. Значения округлены, а не оценены по скриншоту.
- VoiceOver/NVDA, Safari/Firefox, forced-colors, настоящее мобильное устройство и браузерный zoom не проверялись. Проверка accessibility tree не заменяет работу со скринридером. Соответствие всему WCAG AA не заявляется.

## Подтверждённые проблемы

### A1 — высокий приоритет: фокус уходит за экран при открытом мобильном меню

Источник: `themes/theme-plus360/assets/js/footer-modules/top-menu.js:14–21`, `assets/scss/header/_menu.scss`.

Воспроизведение:

1. Открыть главную на ширине 320 px, высота 800 px.
2. Сфокусировать кнопку навигации и нажать Enter.
3. Продолжать нажимать Tab после последней ссылки меню.

Фокус переходит в hero и затем в карточки, хотя `body` остаётся `position: fixed` и прокрутка заблокирована. Через 11 нажатий Tab от кнопки меню фокус был на ссылке четвёртой карточки: её верхняя граница 2461 px при высоте экрана 800 px и scrollY = 0. Контент остаётся доступным в accessibility tree; `main.inert` = false. Escape закрывает меню и возвращает фокус, но обычная последовательность Tab уже нарушена.

Связь с WCAG: 2.4.7 (видимый фокус), 2.4.3 (порядок фокуса); также требует перепроверки клавиатурной доступности 2.1.1. Это не доказанная клавиатурная ловушка: Escape работает.

Рекомендация: согласовать жизненный цикл раскрытого меню, фокус и блокировку прокрутки. Как минимум закрывать меню и снимать блокировку при уходе фокуса из навигации. Если выбирать модель модального меню, нужны полноценные модальные семантика, изоляция фона и удержание фокуса; одного focus trap недостаточно. После изменения проверить Tab/Shift+Tab, Escape, клик снаружи, смену breakpoint и восстановление прокрутки.

### A2 — высокий приоритет: выбор темы обрезается при увеличении текста

Источник: `themes/theme-plus360/assets/scss/footer/_base.scss:29–62`.

На немецкой главной при ширине 320 px и корневом font-size 200% открыть выбор темы в подвале. Панель имеет ширину 240 px и внутреннюю ширину 238 px, но её scrollWidth — 356 px. Текст `Systemeinstellung` заканчивается на x = 356.86 при правой границе панели x = 280; часть надписи обрезана. Проблема воспроизводится уже при одном увеличении текста, без изменения интервалов.

Связь с WCAG: 1.4.4 (масштабирование текста), 1.4.10 (reflow). Совместный сценарий увеличения и text spacing также не проходит для этой панели. Само по себе увеличение интервалов при стандартном размере в проверенном сценарии помещается.

Рекомендация: разрешить текстовым элементам сжиматься и переноситься (`min-inline-size: 0`, overflow-wrap), убрать влияние min-content у fieldset/grid/flex. Ограничить размер панели доступной областью экрана; при недостаточной высоте предусмотреть вертикальную прокрутку. Сохранить radio и подпись целиком доступными без горизонтальной прокрутки.

### A3 — средний приоритет: радиогруппа закрывается на каждой стрелке

Источник: `themes/theme-plus360/assets/js/footer-modules/theme-switcher.js:19–27`.

Воспроизведение: выбран Dark → фокус кнопки темы → Enter → Tab → фокус Dark → ArrowUp.

Браузер выбирает Light, возникает change, панель немедленно закрывается, фокус принудительно возвращается на кнопку. Чтобы дойти до System, приходится снова открывать панель. Стандартное последовательное переключение радиогруппы стрелками прерывается.

Это подтверждённый дефект взаимодействия. Возможная связь с 3.2.2 (изменение контекста при вводе) требует оценки ожидаемого поведения; не объявляется самостоятельным доказанным нарушением AA только по этому наблюдению.

Рекомендация: применять и сохранять тему на change, оставляя панель открытой и фокус на radio. Закрытие — Escape, клик снаружи или повторное нажатие кнопки. Возвращать фокус на кнопку тогда, когда пользователь действительно закрывает панель, не на каждом выборе.

## Улучшения без подтверждённого нарушения AA

1. **Текущий пункт основного меню.** `Homepage` — элемент `<a>` без href и без aria-current; accessibility tree показывает обычный текст. Добавить `aria-current="page"`, осмысленно выбрать ссылку с href или span. Визуальный текущий пункт уже выделен.
2. **Название основной навигации.** Основной nav не имеет названия, тогда как языковой nav и nav услуг имеют. Добавить локализованное имя; юридическое меню подвала можно оформить отдельным именованным nav. Само отсутствие имени у этого nav не означает автоматического провала AA.
3. **Логотип в русской версии.** Оба логотипа используют `.Site.BaseURL` и ведут на немецкую главную. Использовать `.Site.Home.RelPermalink`, чтобы возвращать на главную текущего языка.
4. **Размер ссылок подвала.** Юридические ссылки — 13 px, кликабельные области от 43×37 px. Минимум AA 24 px выполнен; увеличение текста до 15–16 px и высоты до 44 px улучшит читаемость и касание. Не считать 44 px обязательным минимумом AA.
5. **Новая вкладка.** Социальные ссылки открываются с target=_blank без предупреждения. При сохранении такого поведения добавить локализованную информацию о новой вкладке; для mailto убрать ненужный target.

## Что прошло проверку

### Структура и доступные названия

- Один H1, далее H2 секций и H3 карточек/преимуществ, без пропусков уровней.
- Есть banner, main и contentinfo; три секции главной связаны с заголовками через aria-labelledby.
- Язык документа de-DE / ru-RU. Языковые ссылки имеют lang и hreflang.
- Ссылки карточек имеют уникальные имена: «Mehr erfahren — [услуга]» / локализованный эквивалент. Видимый текст включён в доступное имя.
- SVG услуг и управляющих кнопок скрыты от скринридера; дублирующихся id не найдено.
- Немецкие юридические ссылки сохраняются на русской главной и имеют lang=de-DE.
- Названия icon-only кнопок темы и «наверх» доступны в accessibility tree. Native popover сообщает раскрытое состояние; radio имеют подписи и checked, fieldset содержит legend.

### Клавиатура

- Первый Tab открывает видимый skip link; Enter переводит фокус на main-content.
- Закрытые мобильное меню и popover не добавляют скрытые пункты в Tab-порядок.
- Hero-якорь прокручивает к соответствующей карточке; следующий Tab приводит к ссылке именно этой карточки.
- Enter открывает popover, Tab приводит к выбранной radio. Escape закрывает панель. Переходы стрелками требуют исправления A3.
- Escape закрывает мобильное меню и возвращает фокус кнопке; scroll lock применяется. Уход фокуса требует исправления A1.
- «Наверх» доступна с клавиатуры, переводит фокус в main-content и прокручивает страницу к 0.
- Для focus-visible предусмотрена общая контрастная обводка; у skip link она видна. Проверены основные управляющие элементы, но не все состояния во всех браузерах.

### Контраст

| Пара текста / фона | Светлая | Тёмная |
| --- | ---: | ---: |
| Основной текст / фон | 13.74:1 | 13.53:1 |
| Вторичный текст / фон | 5.55:1 | 8.75:1 |
| Вторичный текст / карточка | 5.85:1 | 7.89:1 |
| Вторичный текст / подвал и меню | 4.94:1 | 7.24:1 |
| Акцентные ссылки / фон | 6.28:1 | 7.29:1 |
| Акцентные ссылки / карточка | 6.61:1 | 6.58:1 |
| Текст / основная CTA | 7.02:1 | 7.29:1 |

Используемые пары проходят 4.5:1 для обычного текста. Цвет focus ring на фоне страницы/карточки — минимум 6.28:1 в светлой и 6.58:1 в тёмной теме. Декоративные линии и рамки карточек не оценивались как самостоятельные обязательные управляющие элементы.

Пара text-secondary / surface-hover в светлой теме даёт 4.46:1. Она не обнаружена в текущем обязательном текстовом состоянии главной: на hover кнопка темы меняет цвет иконки на action, подписи radio используют text-primary либо action. Не применять эту пару для нового обычного текста без корректировки.

### Размеры и адаптивность

- 320 px: основной документ без горизонтального переполнения в обоих языках, при обычном размере, 200% и повышенных интервалах. Исключение — внутренняя область popover A2.
- Основная CTA около 199×54 px, кнопки темы и «наверх» 44×44 px, языковая ссылка высотой 44 px, мобильная кнопка меню 72×80 px.
- Ссылки карточек около 110×49 px; итоговая ссылка каталога имеет высоту около 25 px. Минимум 24 px соблюдён в измеренных состояниях.
- На узком экране быстрые ссылки hero скрыты; услуги остаются доступны через основную ссылку секции и карточки.
- Раскрытое меню при 320×480 и тексте 200% имеет внутреннюю вертикальную прокрутку; последняя ссылка достижима внутри области меню.
- После последнего исправления в подвале зарезервировано место для «наверх»; в осмотренных состояниях она не перекрывает кнопку темы.
- В коде предусмотрен prefers-reduced-motion: CSS отключает существенное движение, кнопка «наверх» выбирает instant. Системный режим reduced motion отдельно не эмулировался.
